Pagina web para el Hospital Municipal Eustaquio Aristizabal. 
La misma formo parte del proyecto que decidi realizar para la entrega del trabajo practico final de la cursada "Codo a Codo - Full Stack NodeJS" durante el 2024. 
Fue mi primer pagina web y el primer contacto con JS.


# Estructura del Proyecto

- hospital_fron/
  - api/
    - medicos.json      # Json con toda la data de cada uno de los medicos para el manejo de la agenda de turnos.
  - css/                # Estilos de las paginas.
    - agenda.css
    - caps.css
    - general.css
    - inicio.css
    - personalMedico.css
    - style-contacto.css
    - turnero.css
  - img/                # Archivos de imagenes necesarios para la web.
  - js/                 # Logica de las paginas.
    - agenda.js
    - contacto.js
    - personal.js
    - turnero.js
    - validacion.js
  - pages/              # Paginas secundarias.
    - agenda.html
    - caps.html
    - contacto.html
    - personal.html
    - turnero.html
  - index.html          # Pagina principal.
  - README.md           # Documentación del proyecto
